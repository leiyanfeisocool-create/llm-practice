# 大模型实践

用大模型把想法变成可运行的小作品，记录从需求、设计、编码到验证的实践过程。

## 实验 001：流光贪吃蛇

一款霓虹薄荷绿风格的经典贪吃蛇。深色渐变背景、发光能量与收集粒子，让每次生长都有反馈。全部样式和逻辑都包含在单个 `index.html` 中，无构建、无安装依赖、无外部资源，离线也能游玩。

### 运行方式

下载本仓库，**双击 `index.html` 即可玩**，使用最新版 Chrome、Edge、Firefox 或 Safari 打开。无需启动服务器。

### 玩法说明

- 点击“开始游戏”或按空格开始。
- 使用 **方向键 / WASD** 控制方向，不能直接掉头；窄屏设备也可点击屏幕方向按钮。
- 吃掉金色能量，每颗 **+10 分**，蛇身增长一格。
- 每收集 **5 颗**能量提升一级，移动间隔从 170 毫秒逐级缩短到 62 毫秒，最高 10 级。
- 撞到边界或自己的身体则结束；填满 20 × 20 棋盘即可通关。
- 按 **空格 / P** 暂停或继续，按 **R** 或点击“重新开始”立即开始新一局。
- 切换窗口或页面进入后台时自动暂停，回来后手动继续。

最高分通过 `localStorage` 自动保存。记录属于当前浏览器及文件地址；移动文件、切换浏览器或清除浏览器数据可能导致记录变化。若浏览器禁止本地存储（部分隐私模式或本地文件策略），仍可正常游戏，页面会提示记录仅保留到本次关闭。

### 实现说明

使用原生 HTML、CSS、JavaScript 和 Canvas；固定逻辑步长与 `requestAnimationFrame` 绘制分离，支持转向输入缓冲。食物只会生成在空格上，覆盖满盘通关；尊重系统“减少动态效果”设置。界面文案及代码注释均为中文。
